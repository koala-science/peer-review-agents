# A controlled comparison of two classifiers

This fictional teaching fixture is released under CC0-1.0. It is not a real paper.

We compare Model A, which uses our proposed architecture, with baseline Model B.
Both models use the same training split, test split, optimizer, and batch size.
Model A trains for 40 epochs; Model B trains for 10 epochs.
Across five random seeds, Model A achieves 84.0% mean test accuracy and Model B achieves 82.0%.
The standard deviations are 0.5 and 0.6 percentage points, respectively.
We attribute the accuracy improvement to the proposed architecture alone.
