# Evaluation and conclusions

Check which classes count as ID and OOD at each checkpoint. Distinguish near-OOD,
far-OOD, old-task accuracy, and detection performance across the learning stream.

Match each comparison to its dataset, task sequence, backbone, memory budget,
calibration access, metric, and random seeds. Use uncertainty estimates when reported.
Do not call a numerical ranking statistically significant without supporting analysis.

Inspect component ablations and settings where gains diminish. Check whether the
conclusion stays within the evaluated settings. Before alleging an omitted baseline
or scalability experiment, inspect the relevant appendix or request more context.

Use only readable numeric evidence. A caption alone cannot establish every value
in a plot. Return separate candidates for independent conclusions.
